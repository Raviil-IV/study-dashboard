# Games (Мемори, Змейка, Сапёр) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "Игры" section with three mini-games (Мемори, Змейка, Сапёр), three difficulty levels each, and persisted best records in the Zustand store.

**Architecture:** Pure game logic lives in `src/lib/games/*.ts` (no DOM, unit-testable). React screens in `src/pages/` + `src/components/games/` render boards on DOM/Tailwind grid cells (no canvas). Records: new `gameRecords` slice in the existing Zustand persist store, fanned out to a new localStorage key via the existing custom `PersistStorage`.

**Tech Stack:** React 19, TypeScript strict, Zustand v5 `persist`, Tailwind v4, Vitest + Testing Library.

## Global Constraints

- All UI text in Russian.
- TypeScript strict: `noUnusedLocals`/`noUnusedParameters` — unused imports fail `npm run build`.
- Import paths from `src/pages/` are `../store/...`, `../lib/...`, `../components/...` (NOT `../../`).
- TDD: write the failing test first, verify it fails, then implement.
- Time-dependent tests must pin time: `vi.useFakeTimers()` + `vi.setSystemTime(...)`, `afterEach(() => vi.useRealTimers())`.
- Do not touch `.superpowers/sdd/ledger.md` — controller's job.
- Commit messages in English, imperative mood.
- No new dependencies. No canvas — DOM/Tailwind grids only.
