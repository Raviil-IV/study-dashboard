# Добавление события кликом по дате в сетке месяца

## Задача

В месячном виде расписания нельзя создать событие на конкретный день: приходится открывать форму, переключать тип на «На конкретную дату» и вручную выбирать дату. Нужно, чтобы клик по номеру дня открывал форму нового события с уже заполненной датой.

## Границы

Входит:

- кликабельный номер дня в сетке «Месяц»;
- предзаполнение даты и типа в форме нового события.

Не входит:

- клики по пустому месту ячейки и по чипам событий (они продолжают открывать редактирование);
- быстрое добавление в «Неделе» и «Дне»;
- переключение месяца при клике по серой дате;
- изменения бэкенда и схемы данных.

## Поведение

- Номер дня в каждой из 42 ячеек — кнопка с доступным именем «Добавить событие: 6 августа».
- Клик открывает модалку «Новое событие»: тип — «На конкретную дату», поле «Дата» заполнено, время по умолчанию `09:00–10:30`, «Весь день» выключен, остальные поля пустые.
- Серые даты соседних месяцев работают так же; календарь при этом не переключается.
- Клик по чипу события внутри ячейки по-прежнему открывает редактирование этого события: чипы и номер дня — соседние элементы, а не вложенные кнопки.
- Кнопка «Добавить событие» в шапке продолжает открывать пустую форму с типом «Регулярное».

## Реализация

- `MonthView` получает обязательный проп `onAdd(date: Date)`. Номер дня оборачивается в `<button type="button">`; стиль текста сохраняется, добавляются подсветка при наведении и кольцо фокуса.
- `SchedulePage` хранит `newDate?: string` (ISO). Клик по дате выставляет её и открывает модалку; кнопка в шапке и `openEdit` сбрасывают `newDate`, чтобы дата не «прилипала» к другим сценариям.
- `LessonForm` получает необязательный проп `initialDate?: string` и при отсутствии `initial` открывается в режиме разового события с этой датой. Проп `initial` по-прежнему означает только редактирование: заголовок «Новое событие», без кнопки «Удалить».
- `Modal` при `open = false` не рендерит детей, поэтому форма каждый раз создаётся заново и подхватывает новую дату.

## Тесты

- `src/components/schedule/MonthView.test.tsx` — клик по номеру дня текущего месяца вызывает `onAdd` с этой датой; клик по серой дате соседнего месяца — тоже.
- `src/pages/SchedulePage.test.tsx` — в режиме «Месяц» клик по дате открывает «Новое событие», радио «На конкретную дату» выбрано, поле «Дата» заполнено; после сохранения событие попадает в стор с этой датой и типом `once`.
- Существующие наборы остаются зелёными (283 фронтенд / 131 бэкенд).
