# Design Spec: Игры — Мемори, Змейка, Сапёр

Дата: 2026-08-07
Проект: Study Dashboard (React 19 + Vite 7 + TS strict + Zustand v5 + Tailwind v4 + Vitest)
Ветка: `games`

## 1. Цель

Добавить раздел «Игры» с тремя мини-играми: **Мемори**, **Змейка**, **Сапёр**. Раздел доступен из навигации (sidebar + нижняя навигация), каждая игра — отдельный экран. Лучшие результаты сохраняются в localStorage через существующий Zustand-стор.

## 2. Навигация и маршруты

- В `src/lib/constants.ts` массив `NAV_ITEMS` дополняется пунктом `{ to: '/games', label: 'Игры', icon: '🎮' }` — автоматически появляется в `Sidebar` и `BottomNav`.
- В `src/App.tsx` добавляются маршруты:
  - `/games` → `GamesPage` (хаб с карточками игр)
  - `/games/memory` → `MemoryPage`
  - `/games/snake` → `SnakePage`
  - `/games/minesweeper` → `MinesweeperPage`

## 3. Сложности

| Игра | Лёгкий | Средний | Сложный |
|---|---|---|---|
| Мемори | 4×4 (8 пар) | 4×6 (12 пар) | 6×6 (18 пар) |
| Змейка | 150 мс/шаг | 100 мс/шаг | 70 мс/шаг |
| Сапёр | 9×9, 10 мин | 16×16, 40 мин | 16×30, 99 мин |

- Змейка: скорость — интервал между шагами; ускорение при съедении еды (+10 мс, не быстрее 40 мс).
- Сапёр: первый клик никогда не открывает мину (мины расставляются после первого клика, кроме его клетки).
- Мемори: все карточки на русском — пары из списка эмодзи/слов; при несовпадении открытые карточки переворачиваются через 700 мс.

## 4. Архитектура

Следует паттернам проекта: чистые функции в `src/lib/`, компоненты в `src/components/<domain>/`, страницы в `src/pages/`, состояние в `src/store/useStore.ts`.

### Файлы

**Логика игр (чистая, без DOM, юнит-тестируемая):**
- `src/lib/games/memory.ts` — `createDeck(rows, cols)`, `flipCard`, `checkMatch`, результат (ходы, время)
- `src/lib/games/snake.ts` — `createBoard(size)`, `step(state, direction)`, `setDirection`, `spawnFood`, результат (длина змейки)
- `src/lib/games/minesweeper.ts` — `createEmptyField(rows, cols, mines)`, `placeMines(field, firstRow, firstCol)`, `openCell`, `toggleFlag`, `revealField`, результат (время, открыто клеток)
- `src/lib/games/types.ts` — общие типы: `GameId = 'memory' | 'snake' | 'minesweeper'`, `GameDifficulty = 'easy' | 'medium' | 'hard'`, `GameRecord`

**Хаб и экраны:**
- `src/pages/GamesPage.tsx` — карточки игр с лучшими результатами
- `src/pages/MemoryPage.tsx`, `src/pages/SnakePage.tsx`, `src/pages/MinesweeperPage.tsx` — экраны игр
- `src/components/games/GameCard.tsx` — карточка игры в хабе
- `src/components/games/DifficultyPicker.tsx` — выбор сложности
- `src/components/games/GameResultModal.tsx` — модалка результата (переиспользует `Modal`)
- `src/components/games/memory/MemoryBoard.tsx`, `MemoryCard.tsx`
- `src/components/games/snake/SnakeBoard.tsx`
- `src/components/games/minesweeper/MinesweeperField.tsx`

**Рекорды:**
- В `src/store/useStore.ts` добавляется slice `gameRecords: Record<GameId, Partial<Record<GameDifficulty, number>>>` + метод `submitGameRecord(game, difficulty, value): boolean` (возвращает, побит ли рекорд).
- Новый ключ `gameRecords` в `STORAGE_KEYS`, добавление в `PersistedState`, `getItem`/`setItem`/`migrateState`.
- Направление рекорда: Мемори и Сапёр — меньше (ходы/время), Змейка — больше (длина).

## 5. Интерфейс

- **Хаб:** три карточки (название, эмодзи, описание, лучший результат по каждой сложности), клик — переход в игру.
- **Экран игры:** шапка (название, кнопка «Назад» к хабу), выбор сложности (только до начала игры), поле игры, статус (ходы/время/длина), кнопка «Заново».
- **Управление:**
  - Мемори — клик по карточке.
  - Змейка — стрелки клавиатуры + свайпы на тач-устройствах; пауза пробелом.
  - Сапёр — клик открыть, правый клик флаг; на тач-устройствах тумблер «Открыть/Флаг» над полем.
- **Конец игры:** модалка результата — счёт, время, «Новый рекорд!» при достижении.
- Все тексты на русском. Тёмная тема — через существующие Tailwind-классы `dark:`.

## 6. Ошибки и edge cases

- Разворот таймеров: играть после паузы/выхода — таймер считает только во время игры (запуск с шагом).
- Змейка: столкновение со стеной/собой — конец игры; запрет разворота на 180° за один шаг.
- Сапёр: клик по открытой клетке игнорируется; флаг не ставится на открытую клетку; победа — открыты все клетки без мин.
- Мемори: клик по уже открытой/найденной карточке игнорируется; клик по третьей карточке во время показа пары — игнорируется (запрет).
- Рекорды: у каждой игры отдельно по сложности; отсутствие рекорда показывается как «—».
- Первый клик в Сапёре не мина.

## 7. Тестирование

- Юнит-тесты `src/lib/games/*.test.ts`:
  - memory: генерация колоды (чётное число пар, все уникальны), проверка совпадения, сброс
  - snake: шаг в направлении, съедание еды (рост), столкновение со стеной и собой, запрет 180°
  - minesweeper: расстановка мин (первый клик безопасен), открытие пустой клетки (BFS), победа/поражение, флаги
- Тест стора `src/store/useStore.test.ts`: добавление рекорда, не-рекорд, направление (мин/макс).
- Smoke-тесты страниц: `GamesPage` рендерит три карточки; маршруты игр рендерятся.
- Время в тестах — `vi.useFakeTimers` с системным временем.

## 8. Ограничения

- Без новых зависимостей.
- Без canvas — сетки на DOM/Tailwind.
- Все данные локально.
- TypeScript strict: `noUnusedLocals`/`noUnusedParameters` — неиспользуемые импорты ломают сборку.
