# Design Spec: Расписание — вкладка «Месяц»

Дата: 2026-08-08
Проект: Study Dashboard (React 19 + Vite 7 + TS + Zustand + Tailwind v4)

## 1. Цель

Добавить в расписание третью вкладку **«Месяц»**: календарная сетка всего месяца с занятиями по дням (как на вкладке «Неделя»), с возможностью листать месяцы и возвращаться к текущему месяцу.

## 2. UX-требования

- В `SchedulePage` появляется третья вкладка в `Tabs`: **День / Неделя / Месяц**.
- При открытии вкладки показывается текущий месяц.
- Шапка месячного вида: стрелки **← / →** по краям, по центру название месяца («Август 2026»), справа кнопка **«Сегодня»** — возвращает к текущему месяцу. Кнопка видна всегда; когда уже выбран текущий месяц, она неактивна (`disabled`).
- Сетка календаря: 7 колонок (Пн–Вс, как в `WeekView`), 6 рядов (42 ячейки) — дни соседних месяцев заполняют пустоты.
- Ячейка дня:
  - число месяца; дни соседних месяцев отображаются приглушённо (`text-gray-300` / `dark:text-gray-600`);
  - сегодняшний день — акцентная рамка (ring);
  - максимум **4** занятия (время + цветная точка + название, truncate); при большем числе — строка «+ ещё N»;
  - у каждого занятия кнопки «Редактировать» и «Удалить» (как в `WeekView`).
- Одноразовые занятия (`type: 'once'`) показываются только в свою дату; регулярные (`type: 'weekly'`) — по `weekday`, как в `DayView`/`WeekView`.

## 3. Утилита календарной сетки (`src/lib/date.ts`)

Новая чистая функция (паттерн проекта — чистые функции в `lib` с юнит-тестами):

```ts
export interface CalendarDay {
  date: Date
  iso: string // YYYY-MM-DD
  inMonth: boolean // true — день текущего месяца
}

export function getMonthGrid(year: number, month: number): CalendarDay[] {
  // 42 ячейки, первая — понедельник, попадающий в неделю 1-го числа
}
```

Расчёт первой ячейки: `first = new Date(year, month, 1)`, сдвиг `(first.getDay() + 6) % 7` дней назад → понедельник сетки; от него 42 дня вперёд. `inMonth` по `date.getMonth() === month`.

Кнопка «Сегодня» не требует новой утилиты — сравнение `cursor` с `new Date()` (год/месяц) в компоненте.

## 4. Компонент `MonthView` (`src/components/schedule/MonthView.tsx`)

- Пропсы: `{ lessons: Lesson[]; onEdit: (l: Lesson) => void; onDelete: (id: string) => void }` — как у `WeekView`.
- Состояние: `cursor: Date` (хранит месяц, «первое число»), `useState(() => ...)`, инициализация — текущий месяц.
- Диапазон: `getMonthGrid(cursor.getFullYear(), cursor.getMonth())`.
- Шапка: кнопки ←/→ (`cursor ± 1 месяц`), заголовок (`toLocaleDateString('ru-RU', { month: 'long', year: 'numeric' })`), кнопка «Сегодня» (неактивна на текущем месяце).
- Сетка: строка заголовков `WEEKDAYS_SHORT` (Пн–Вс) + 6 рядов ячеек `grid grid-cols-7`.
- Ячейка дня (`CalendarDay`):
  - число (день соседнего месяца — приглушённый);
  - сегодня — акцентная рамка (`ring-2 ring-indigo-500`, как в `WeekView`);
  - фильтр занятий идентичен `DayView`/`WeekView`: `l.type === 'once' ? l.date === day.iso : l.weekday === day.date.getDay()`, сортировка по `startTime`;
  - до 4 занятий: строка «время – название» с цветной точкой (truncate), кнопки `IconButton` edit/trash у каждой;
  - если занятий > 4 — пятая строка «+ ещё N»;
  - пустой день — «—» (как в `WeekView`).
- Высота ячеек выравнивается через `min-h-*`, чтобы ряды сетки были ровными.

## 5. Интеграция (`src/pages/SchedulePage.tsx`)

- Тип вкладок расширяется: `'day' | 'week' | 'month'`; в `Tabs` добавляется `{ value: 'month', label: 'Месяц' }`.
- При `view === 'month'` рендерится `<MonthView lessons={lessons} onEdit={openEdit} onDelete={handleDelete} />`.
- Существующие `openEdit`/`handleDelete` (модалка `LessonForm` + `window.confirm`) переиспользуются без изменений.

## 6. Тесты

- `src/lib/date.test.ts` — unit-тесты `getMonthGrid`:
  - длина всегда 42, первая ячейка — понедельник;
  - `inMonth` корректно помечает дни соседних месяцев (месяцы, начинающиеся не с понедельника, и заканчивающиеся не в воскресенье);
  - граничные случаи: декабрь → январь (перенос года).
- `src/pages/SchedulePage.test.tsx` — компонентные тесты:
  - вкладка «Месяц» есть, открывается и показывает текущий месяц;
  - регулярное занятие отображается в своей ячейке, разовое — только в свою дату;
  - при >4 занятиях в день появляется «+ ещё N»;
  - стрелка «→» листает месяц (заголовок меняется), «Сегодня» возвращает к текущему;
  - edit/delete из месячного вида работают (по аналогии с существующим тестом week view).

Валидация: `npm run test` и `npm run build` — зелёные.

## 7. Файлы под правкой

- `src/lib/date.ts` — `CalendarDay`, `getMonthGrid`
- `src/components/schedule/MonthView.tsx` — новый компонент
- `src/pages/SchedulePage.tsx` — третья вкладка, рендер `MonthView`
- Тесты: `src/lib/date.test.ts`, `src/pages/SchedulePage.test.tsx`

## 8. Критерии приёмки

1. В `Tabs` расписания три вкладки: День, Неделя, Месяц.
2. Месячный вид показывает календарную сетку текущего месяца: дни недели Пн–Вс, 42 ячейки, дни соседних месяцев приглушены, сегодняшний день выделен рамкой.
3. Занятия отображаются в своих днях: регулярные по дню недели, разовые по дате; лимит 4 + «+ ещё N».
4. Кнопки ←/→ листают месяцы, «Сегодня» возвращает на текущий (неактивна, когда он уже выбран).
5. Редактирование и удаление занятий работают из месячного вида так же, как из недельного.
6. `npm run test` и `npm run build` зелёные.
