# Техническое задание: учебный сайт Study Dashboard

Ты — senior full-stack разработчик. Твоя задача — спроектировать и начать реализацию веб-приложения для учёбы.

Если где-то в ТЗ нет точных деталей, принимай разумное решение сам, но не усложняй MVP. Главная цель — получить рабочий, аккуратный и полезный сайт без лишнего оверинжиниринга.

---

## 1. Общая идея проекта

Нужно сделать веб-приложение для организации учёбы.

Название проекта: `Study Dashboard`.

Суть приложения: пользователь может хранить в одном месте расписание занятий, задачи, дедлайны, конспекты, а также использовать таймер фокусировки для учёбы.

Приложение должно быть полезным для школьника или студента.

---

## 2. Цель MVP

Сделать первую рабочую версию сайта, в которой есть:

1. Главная страница с обзором дня.
2. Расписание занятий.
3. Задачи и домашние задания.
4. Дедлайны и экзамены.
5. Конспекты / заметки.
6. Таймер фокусировки Pomodoro.

Внешние API на первом этапе не использовать.

Расписание пользователь добавляет вручную.

Данные можно хранить локально в браузере через `localStorage`.

---

## 3. Технические требования

Используй следующий стек:

- Frontend: React + Vite + TypeScript.
- Роутинг: React Router.
- Стили: Tailwind CSS.
- Состояние: React Context или Zustand.
- Хранение данных: `localStorage`.
- Без бэкенда на первом этапе.
- Без внешних API на первом этапе.
- Интерфейс на русском языке.
- Адаптивная вёрстка: должно нормально выглядеть на телефоне и компьютере.
- Желательно поддержать светлую и тёмную тему.

Если ты считаешь, что для конкретной части лучше использовать другую библиотеку, выбери минимально простое и стабильное решение.

## 5. Главная страница

Главная страница должна показывать краткую сводку на текущий день.

Блоки:

1. Приветствие и текущая дата.
2. Задачи на сегодня.
3. Ближайшие дедлайны.
4. Расписание на сегодня.
5. Быстрый запуск таймера фокусировки.
6. Краткая статистика:
   - сколько задач выполнено;
   - сколько занятий сегодня;
   - сколько дедлайнов скоро.

Пример визуальной структуры:

```text
Привет! Сегодня четверг, 6 августа.

Сегодня:
- Математика 08:30
- Английский 10:15

Задачи на сегодня:
- Сделать домашку по алгебре
- Выучить 20 английских слов

Ближайшие дедлайны:
- Проект по информатике — через 3 дня
- Тест по истории — через 5 дней

[Начать фокусировку]
```

## 6. Расписание занятий

Раздел `/schedule`.

Пользователь должен мочь:

- добавлять занятие;
- редактировать занятие;
- удалять занятие;
- смотреть расписание на день;
- смотреть расписание на неделю;
- задавать цвет предмету;
- указывать место или ссылку.

Поля занятия:

```ts
interface Lesson {
  id: string;
  title: string;
  weekday: number;
  startTime: string;
  endTime: string;
  location?: string;
  note?: string;
  color?: string;
}
```

Где `weekday`:

```text
0 — воскресенье
1 — понедельник
2 — вторник
3 — среда
4 — четверг
5 — пятница
6 — суббота
```

Форма добавления занятия должна содержать:

- название предмета;
- день недели;
- время начала;
- время окончания;
- кабинет / ссылка;
- заметка;
- цвет.

Расписание на день должно сортироваться по времени начала.

Нужно показывать текущий день по умолчанию.

Дополнительно желательно:

- показать, идёт ли занятие прямо сейчас;
- показать следующее занятие;
- показать, сколько минут осталось до следующего занятия.

Внешние API расписания не использовать.

## 7. Задачи

Раздел `/tasks`.

Пользователь должен мочь:

- добавлять задачу;
- редактировать задачу;
- удалять задачу;
- отмечать задачу выполненной;
- фильтровать задачи;
- сортировать задачи.

Поля задачи:

```ts
interface Task {
  id: string;
  title: string;
  subject?: string;
  description?: string;
  dueDate?: string;
  priority: "low" | "medium" | "high";
  status: "todo" | "in-progress" | "done";
  createdAt: string;
  completedAt?: string;
}
```

Приоритеты:

```text
low — низкий
medium — средний
high — высокий
```

Статусы:

```text
todo — не начато
in-progress — в процессе
done — выполнено
```

Функции:

- список всех задач;
- фильтр по статусу;
- фильтр по приоритету;
- фильтр по предмету;
- просроченные задачи;
- задачи на сегодня;
- отметка выполнения.

Пример задачи:

```text
Название: решить №1–5 по алгебре
Предмет: Математика
Дедлайн: 2026-08-08
Приоритет: высокий
Статус: в процессе
```

## 8. Дедлайны

Раздел `/deadlines`.

Нужно хранить важные учебные даты.

Типы:

```text
exam — экзамен
test — контрольная / тест
project — проект
homework — домашнее задание
other — другое
```

Поля:

```ts
interface Deadline {
  id: string;
  title: string;
  type: "exam" | "test" | "project" | "homework" | "other";
  subject?: string;
  date: string;
  time?: string;
  note?: string;
  createdAt: string;
}
```

Функции:

- добавление дедлайна;
- редактирование;
- удаление;
- список будущих дедлайнов;
- список прошедших дедлайнов;
- сортировка по дате;
- отображение количества оставшихся дней.

Пример:

```text
Экзамен по истории
Дата: 2026-08-20
Осталось: 14 дней
```

Цветовая маркировка:

```text
Красный — осталось 0–2 дня
Жёлтый — осталось 3–7 дней
Зелёный — осталось больше 7 дней
```

## 9. Конспекты / заметки

Раздел `/notes`.

Пользователь должен мочь:

- создавать заметки;
- редактировать заметки;
- удалять заметки;
- искать заметки;
- закреплять заметки;
- указывать предмет;
- добавлять теги.

Поля:

```ts
interface Note {
  id: string;
  title: string;
  subject?: string;
  content: string;
  tags: string[];
  pinned: boolean;
  createdAt: string;
  updatedAt: string;
}
```

На первом этапе можно использовать обычный textarea.

Позже можно заменить на rich-text editor.

Список заметок должен показывать:

- заголовок;
- предмет;
- краткий фрагмент текста;
- дату обновления;
- закреплена ли заметка.

Желательно сделать поиск по названию и содержимому.

## 10. Таймер фокусировки

Раздел `/focus`.

Реализовать таймер Pomodoro.

Настройки по умолчанию:

```text
Работа: 25 минут
Короткий перерыв: 5 минут
Длинный перерыв: 15 минут
```

Функции:

- старт;
- пауза;
- сброс;
- переключение режима работа/отдых;
- отображение оставшегося времени;
- счётчик завершённых сессий;
- привязка сессии к предмету или задаче.

Поля сессии:

```ts
interface FocusSession {
  id: string;
  label?: string;
  subject?: string;
  startedAt: string;
  durationMinutes: number;
  completed: boolean;
}
```

Желательно показать прогресс:

```text
Сессия: 2 из 4
Режим: Работа
Осталось: 24:35
```

Можно добавить звуковой сигнал в конце сессии, но это не обязательно.

## 11. Хранение данных

Все данные MVP хранить в `localStorage`.

Создать отдельные ключи:

```text
study-dashboard:lessons
study-dashboard:tasks
study-dashboard:deadlines
study-dashboard:notes
study-dashboard:focus-sessions
study-dashboard:settings
```

Данные хранить в JSON.

Нужно реализовать хуки или сервисы:

```ts
useLocalStorage<T>(key: string, initialValue: T)
```

или отдельный storage service:

```ts
loadState()
saveState()
```

При загрузке приложения данные должны восстанавливаться.

## 20. Критерии готовности MVP

MVP считается готовым, если:

1. Можно открыть сайт.
2. Работает навигация между страницами.
3. Можно добавить занятие в расписание.
4. Расписание показывает занятия на выбранный день.
5. Можно добавить задачу.
6. Можно отметить задачу выполненной.
7. Можно добавить дедлайн.
8. Видно, сколько дней осталось до дедлайна.
9. Можно создать заметку.
10. Можно найти заметку через поиск.
11. Работает таймер Pomodoro.
12. Данные сохраняются после перезагрузки страницы.
13. Интерфейс нормально выглядит на мобильном экране.
14. Есть светлая и тёмная тема.
